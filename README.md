# ♞ Шахматы с другом

Шахматы для игры с другом по сети в браузере, с подсказками Stockfish прямо во время партии.
Это статический сайт: он работает на GitHub Pages без своего сервера и без сборки.

## Возможности

- **Игра по сети по ссылке.** Один игрок создаёт партию, второй открывает ссылку. Ходы идут напрямую между браузерами (WebRTC через PeerJS).
- **Оценка каждого хода, как на chess.com:** блестящий `!!`, лучший `★`, отличный `!`, хороший `✓`, неточность `?!`, ошибка `?`, зевок `??`. Значок появляется на доске и в списке ходов. После ошибки показывается, какой ход был лучше.
- **Шкала оценки** (eval bar) и **точность** каждого игрока.
- **Лучший ход:** в ⚙ Настройках можно включить стрелку с лучшим ходом в текущей позиции.
- **Stockfish 18 (NNUE)** считает каждую позицию на глубину 22. Расчёт детерминированный, поэтому оценки у обоих игроков совпадают.
- **Премувы:** пока ходит соперник, можно заранее сделать свой ход. Он выполнится сразу, если окажется допустимым. Отмена: клик по пустому полю или правой кнопкой.
- **Стрелки и отметки** правой кнопкой мыши, как на chess.com: тянуть — стрелка, клик — поле. Shift — зелёный, Ctrl — красный, Alt — синий.
- **Звуки** хода, взятия, шаха, рокировки, превращения и конца партии.
- Ничья, сдача, реванш (цвета меняются), чат, просмотр истории (← →).
- Если вкладка хоста перезагрузится, партию можно продолжить кнопкой «Продолжить» в меню. Гость переподключится сам.
- Режим игры на одном устройстве с отменой хода, подходит и для анализа.

Подсказки движка считаются у каждого игрока на его собственном устройстве. Настройки у каждого свои.

## Как выложить на GitHub Pages

1. Создайте на GitHub новый репозиторий, например `chess`.
2. Загрузите в него содержимое этой папки: `index.html`, `style.css`, папки `js/` и `engine/`.
   Это можно сделать через кнопку **Add file → Upload files** или через git:
   ```
   git init
   git add .
   git commit -m "Chess"
   git branch -M main
   git remote add origin https://github.com/ВАШ_НИК/chess.git
   git push -u origin main
   ```
3. В репозитории откройте **Settings → Pages**. В разделе **Source** выберите `Deploy from a branch`, ветку `main` и папку `/ (root)`, затем нажмите **Save**.
4. Примерно через минуту сайт заработает по адресу `https://ВАШ_НИК.github.io/chess/`.

## Как играть

1. Откройте сайт, введите имя, выберите цвет и нажмите **«Создать и получить ссылку»**.
2. Отправьте ссылку другу. Партия начнётся, когда он её откроет.
3. Пока партия идёт, не закрывайте вкладку: хост держит игру у себя.

## Как это устроено

| Файл | Что делает |
|---|---|
| `js/app.js` | Логика партии, интерфейс, сетевой протокол |
| `js/board.js` | Доска: клики, перетаскивание, стрелки, значки |
| `js/engine.js` | Stockfish 18 в Web Worker (файлы в `engine/`) |
| `js/sounds.js` | Звуки ходов (Web Audio) |
| `js/analysis.js` | Классификация ходов по потере шансов на победу, точность |
| `js/net.js` | P2P-соединение через PeerJS |

Stockfish 18 (stockfish.js, GPLv3, лицензия в `engine/Copying.txt`) лежит в папке `engine/`. С CDN загружаются chess.js (правила), PeerJS и изображения фигур с Wikimedia Commons (набор Cburnett, CC BY-SA 3.0).
Для соединения игроков используется бесплатный публичный сервер PeerJS.
Если у кого-то из игроков очень строгий NAT или корпоративная сеть, прямое соединение может не установиться.

Локальный запуск: подойдёт любой статический сервер, например `npx serve .`.
Если открыть `index.html` двойным щелчком (`file://`), модули не загрузятся.
